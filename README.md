# Empirical Learning of Effective Assistance Torques in Wearable Exoskeletons

Project website for the CoRL 2026 paper:
**"Empirical Learning of Effective Assistance Torques in Wearable Exoskeletons via Velocity-Constrained Data Collection"**

*Jonathan Tseng, Six Skov, Keenon Werling, Steve Collins, Scott Delp, C. Karen Liu*  
*Stanford University (CS, ME, Bioengineering, The Movement Lab, Human Performance Lab)*

## Live Website
Hosted on GitHub Pages: [https://Stanford-TML.github.io/exo-gravcomp/](https://Stanford-TML.github.io/exo-gravcomp/)

## Local Development
Run a local static server:
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.
